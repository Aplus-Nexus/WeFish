# WeFish Edge 行阅读器

这是 WeFish 的 Edge Manifest V3 扩展。它通过桌面端只监听 `127.0.0.1` 的本地联动接口读取当前行，不接触微信读书 Cookie、API Key 或账号数据。

支持三种浏览器内展示方式：

- Edge 侧栏：持续显示当前行、全文行数、百分比和真实 SVG 进度环。
- 扩展弹出面板：上一行、下一行、暂停/启动，以及打开侧栏。
- 当前网页浮层：在网页内容区域顶部显示当前行。点击“在当前网页显示浮层”即可切换。

地址栏属于 Edge 的原生浏览器界面，普通扩展不能把自定义 DOM 直接嵌进地址栏。扩展通过官方 Side Panel API 和网页浮层提供同样的随手阅读体验；地址栏只能作为扩展的触发入口，不能作为第三方渲染区域。

## 本地安装

1. 启动 WeFish 1.0.6 或更新版本。
2. 在 Edge 打开 `edge://extensions`，打开右上角“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本目录。
4. 点击扩展图标，打开 Edge 侧栏或当前网页浮层。

默认联动地址为 `http://127.0.0.1:27183`。如果端口被占用，可以用 `WEFISH_INTEGRATION_PORT` 启动 WeFish，但扩展的 `host_permissions` 也要同步改成对应端口。
